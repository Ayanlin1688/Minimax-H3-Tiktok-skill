【用户需求输入卡】
--------------------------------------------------------------------------------
1. 【产品名称】：[例如：可折叠磁吸 COB 工作灯 / 抽真空保鲜机 / 金属框墨镜]

2. 【产品图】：[上传 2–3 张：正面含键位 + 背面含结构 + 细节特写]
   ※ 结构越全，产品越不会变形。

3. 【品类 C】：[可多选]
   [ ] C1 日用百货     [ ] C2 美妆个护     [ ] C3 车载汽配    [ ] C4 时尚配件
   [ ] C5 穿戴（T 失效）[ ] C6 食品/清洁    [ ] C7 强反光透明  [ ] C8 多人协作

4. 【形态 T】：[T1 微型 <10cm / T2 小型 10–18cm / T3 中型 18–35cm /
              T4 长条形 >35cm 或长宽比>4:1 / T5 超大件 / 穿戴类=不适用]

5. 【产品结构锁六项】（缺一必变形）：
   ① 整体比例（多长 / 长宽比）
   ② 颜色分布（哪一段什么色，不要写"红色点缀"）
   ③ 按键（几个 / 方还是圆 / 在哪个位置 / 有没有旋钮）
   ④ 端头（有没有脚座 / 磁吸盘 / 卡扣 / 挂钩）
   ⑤ 线缆（颜色 / 是否可见）
   ⑥ 表面工艺（哑光 / 亮面 / 磨砂 / 荔枝纹）

6. 【本片使用状态（展态）】：
   [ ] 完全展开锁定 / [ ] 组装完成 / [ ] 已装填 / [ ] 已佩戴上身

7. 【场景】：[例如：美国家用车库，卷帘门半升；或 带窗的小厨房；或 卧室角落开落地灯]

8. 【人物】：[年龄 / 发型 / 衣着 / 职业感]
   示例：灰白短发，五十多岁，深蓝工装衬衫，袖子卷到小臂

9. 【口径与口音】：[California Casual / Texas Drawl / New York Fast / Everyday BFF / 普通话]

10. 【时长】：[默认 15 秒]　※ 15 秒内最多 2–3 个镜头（铁律 S）

11. 【输出模式】：
    [ ] 官方 Context-IR 三字段　[ ] 单段 Master Prompt　[ ] 双模全输出（推荐）

【系统会自动补全的固定段（你不用管）】
--------------------------------------------------------------------------------
· 固定段 1 传感器与机身：暗部噪点 + 高光溢出 + 两侧白平衡不一致 + 单手举机手臂疲劳微动
· 固定段 2 人物真实度：五锚点（毛孔/细纹/痣/胡茬/眼睛虹膜+小方形高光）+ 面部不对称
· 固定段 3 动作与说话不完美：1 处手部微失误 + ≥2 项语言不完美
· 固定段 4 场景杂乱：5–8 件与产品无关的杂物 + 声明全程不动 + 中性平光
· 固定段 5 连续性总锁：全片只有一件产品，切镜交代承接
· 固定段 6 声音：2–4 句持续环境底噪
· 固定段 7 负向提示词：全部禁止项集中于此，正向段零否定词

【交付前必须全过的"真实感六问"】
--------------------------------------------------------------------------------
1. 有噪点 / 高光溢出 / 白平衡不均吗？　　→ 没有 = 干净得像渲染图
2. 有机身手臂疲劳微动吗？　　　　　　　　→ 没有 = 像三脚架
3. 场景有 5 件以上无关杂物吗？　　　　　　→ 没有 = 干净得像样机图
4. 产品有灰尘 / 指纹 / 磨损吗？　　　　　→ 没有 = 产品全新无瑕 = 假
5. 说话有卡壳 / 换气 / 音量不均吗？　　　→ 没有 = 广告配音腔 = 假
6. 手有打滑 / 没按到 / 重抓吗？　　　　　→ 没有 = 动作像机械臂
