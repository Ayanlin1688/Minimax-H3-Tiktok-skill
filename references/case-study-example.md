## 四、为什么这一版会自动避开上一版四个坑

| 上一版的坑 | 这一版对应的写法 |
|---|---|
| 产品悬空 | Shot2 写「两个金属圆盘面同时贴平压在钢板面，两表面相接处有一条清晰接触线，无缝隙」——有接触线就画不出悬空 |
| 手指悬空点按钮 | Shot3 写「单手从右下角进入，**其拇指**按下方形键」——拇指归属这只手，不另生手 |
| 残影重影 | Shot1–4 全部 `static` 镜头；Shot2 只写手在动、镜头不动；Shot3 只写一次拇指按压 |
| 产品分身 | 每镜第一句连续态锁 + 总锁「never appears twice in the same frame」 |
| 蜡人红脸 | 删除所有 redness；改用五锚点（毛孔/细纹/痣/胡茬/**眼睛虹膜+小方形高光**） |
| 灯带拖影 | 写「平亮均匀、边缘清晰、端到端亮度一致」，禁用 glowing/shining 类词 |
